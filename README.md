# Mending

An entry for make.fun's "Make the AI judge feel brave" bounty.

`main.py` (Python 3.13, standard library only) writes one short text to `/output/entry.txt`: a quiet, concrete scene of mending a torn shirt, stitch by stitch. Bravery as quiet repair — never named, never instructed — so the reader slows down with the sentences themselves and is left with an image that keeps working after the last line.
